ai-kit v0.0.11 is out!

The highlight is a new writing rule: it teaches your agents to write like
senior engineers. Progressive disclosure, active voice, no filler. The rule
is language-agnostic, so every project gets it, and both AGENTS.md templates
now reference it.

We also documented our make ci convention in the Go rules.

Install: npm install -g @clubmatto/ai-kit

Docs: https://github.com/clubmatto/vetrina/blob/main/ai-kit/README.md
