## LinkedIn

A system prompt is not magic text. Modern models process instructions in ranks:
root ➡️ system ➡️ developer ➡️ user. The harness writes the system
prompt, and what it writes there outranks you.

That rank is why your harness can configure the agent the same way for every
user, and guard what you type. And the prompt carries three things in almost
every harness: where it is, your rules, and what it learned.

Learn more here: https://matto.club/writing/how-coding-agents-work/the-system-prompt/
