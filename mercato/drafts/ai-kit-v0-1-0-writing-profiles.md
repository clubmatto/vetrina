## LinkedIn

🚀 ai-kit v0.1.0 is out 🚀

v0.0.11 taught agents one writing rule. That turned out not to fit every job:
the voice that suits a README does not suit a launch post, and docs are not
marketing.

So the writing rule is now four files. A universal core covers voice,
structure, accuracy, and mechanics. Three profiles add rules without replacing
them: technical for docs, changelogs, and code comments; editorial for posts
and essays; marketing for launch and social copy. The router in writing.md
points the agent at the profile that matches the task.

It is a rules-only release: no new languages this time.

Install: npm install -g @clubmatto/ai-kit

Docs: https://github.com/clubmatto/vetrina/blob/main/ai-kit/README.md
