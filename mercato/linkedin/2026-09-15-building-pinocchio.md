📢 How coding agents work, part 2: building one from scratch 📢

We opened the series by shortlisting ten open-source agents to take apart.
Before we get to them, we're building our own to see what's inside. Pinocchio is
a tiny agent in Go, and we grow it one version at a time: the loop, tool calls,
a permission prompt, context compaction, and a session file.

Turns out the agent loop is genuinely tiny. The hard part of a real coding
agent lives _around_ the loop.
