🚀 FakeData Pro is here 🚀

Generating test data for relational databases is notoriously annoying because constraints, data types, foreign keys get in the way when all you need is some test data. Scripting a solution only works until you need to backport schema changes.

This is why we wrote FakeData Pro: point the CLI to your database, and in one command you get production-like data that respects every constrains. No custom scripts, no broken tests.

Some of the included batteries:

- deterministic seeding
- foreign key integrity
- dry run mode
- sensible default with straightforward customisation

FakeData Pro supports MySql, PostgreSQL, and sqlite. More to come soon so stay tuned!
