📢 New article: tuning a slow Postgres query with FakeData Pro. 📢

Slow queries are conceptually simple: find the slowest piece, make it faster.
The hard part is having realistic data around to reason about them.

In this article, we explain how we use FakeData Pro to generate 5M realistic
line items rows into Postgres in a single command, then walk through EXPLAIN
ANALYZE to improve the query performance.
